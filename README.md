# Oovy & Ray's Money

Multi-currency household budget application with automated forecast engine, recurring transaction rules, and weekly review system.

**Stack:** React 18, TypeScript, Vite, Supabase (PostgreSQL), Tailwind CSS

## Features
- Multi-currency support (GBP £ / NZD NZ$)
- Automated budget forecasting with pure mathematical projection
- Recurring transaction scheduling
- Weekly budget review with comparison engine
- Household-level accounts (no individual ownership)

## Getting Started
```bash
npm install
npm run dev
```
